# 公交跳车检查助手（纯前端复刻版）

复刻自飞书妙搭应用「公交跳车检查助手」的纯前端单机版：数据保存在浏览器 `localStorage`，无后端、无登录、无拍照识别；移动端优先，电脑端为辅。

## 功能

- **台账**：列表视图（按线路/车牌/检查人/日期范围筛选、分页、编辑、删除）与当日表格（14 项检查符号表、打印）
- **新建/编辑**：线路、车牌/自编号、驾驶员、售票员、上下车时间/地点，14 项检查项三态（合格/不合格/待确认），备注、检查人、检查日期
- **详情**：完整查看一条检查记录，可编辑、删除
- **统计**：日/周/月维度 + 线路/检查人筛选，展示检查车次总数、整体合格率、整体不合格率、各项目合格率、不合格项 Top 10
- **导出**：按日期范围（默认本月 1 日至今天）+ 线路/车牌筛选，导出 Excel (.xlsx) 或 CSV（表头与原版应用一致）
- **基础数据**：线路、驾驶员、售票员、站点管理（站点按线路维护并支持排序）
- **备份/恢复**：导出 JSON 备份文件、导入备份覆盖恢复（防止清理浏览器缓存丢数据）

## 运行

需要 Node.js（≥ 18）与包管理器（pnpm 或 npm）。

```bash
npm install        # 或 pnpm install
npm run dev        # 启动开发服务器
```

开发服务器监听 `0.0.0.0`，本机访问 `http://localhost:5173`。

### 手机通过局域网访问

1. 电脑与手机连同一个 Wi-Fi；
2. 电脑上执行 `ipconfig` 查看本机 IPv4 地址（如 `192.168.1.100`）；
3. 手机浏览器打开 `http://192.168.1.100:5173`；
4. 若无法访问，请检查 Windows 防火墙是否放行 Node.js 的入站连接（首次运行会弹出防火墙授权，勾选允许）。

### 生产构建

```bash
npm run build      # 产物在 dist/
npm run preview    # 本地预览构建产物（同局域网可访问）
```

## 测试

```bash
npm test           # Vitest 单测 + 页面冒烟测试
```

## 数据说明

- 所有数据仅保存在当前浏览器的 `localStorage`（键名 `busCheck.records`、`busCheck.basicData`、`busCheck.version`）。
- 换浏览器、换设备或清理浏览器缓存都会丢失数据，请定期到「基础数据 → 备份/恢复」导出 JSON 备份。
- 两台设备间不自动同步；如需迁移，在旧设备导出备份，在新设备导入即可。

## 技术栈

React 18 + Vite 6 + Tailwind CSS 4 + SheetJS（xlsx）+ Vitest。全部为浏览器端代码，可离线使用。
